# CozySpace 🌸

> A private, real-time digital sanctuary for two. A quiet space to send hugs, exchange love notes, share memories, and countdown to meaningful milestones.

---

## 📖 Project Documentation & Pitch
Detailed project vision, feature matrix, zero-cost architecture plan, and PostgreSQL DDL schema are documented in:
👉 **[docs/PROJECT_PITCH.md](docs/PROJECT_PITCH.md)**

---

## 🚀 Recommended Tech Stack (100% Free Tier)
* **Frontend:** Vite + Vanilla JS / Tailwind CSS
* **Frontend Hosting:** [Vercel](https://vercel.com) / [Cloudflare Pages](https://pages.cloudflare.com)
* **Backend & Database:** [Supabase](https://supabase.com) (PostgreSQL, Supabase Auth, Supabase Storage, and WebSockets Realtime)
